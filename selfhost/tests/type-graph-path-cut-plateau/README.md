# Path-cut search state plateau

This project builds one immutable fixture before repeated queries. It isolates
production search-state allocation from children generated by a callback.
Compile with `ASHES_RC_LEAKCHECK=1`, then run the same binary with:

- `new1000` and `new10000`: production path-sensitive fallback; expected `done` and
  equal live counters. Validated stage 0 plain/poison: 1/1; stage 1 plain: 25/25.
- `old1000` and `old10000`: existing regular search returning `None` on the same
  changing generic ancestor; validated live counters 1/1 in all three modes.

Use compile-time `ASHES_RC_POISON=1` for stage-0 poison checks. Stage 1 does not
emit poison instrumentation. Keep compiler leakcheck stderr separate from emitted
program counters and record scoped build/run timings separately.
